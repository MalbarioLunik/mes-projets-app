# Mes Projets

Tableau blanc multi-projets (to-do, notes, liens, vidéos), synchronisé avec GitHub.

👉 **Ouvrir l'appli : https://malbariolunik.github.io/mes-projets-app/**

Ce dépôt est public mais ne contient **que l'appli** (`index.html`), aucune donnée.
Tes projets sont enregistrés dans ton navigateur et, si tu le relies dans ⚙, dans ton dépôt **privé** (ex. `mes-projets-data`).

## Sur téléphone
Ouvre le lien ci-dessus → menu du navigateur → « Ajouter à l'écran d'accueil » → ⚙ pour relier GitHub.

## Raccourcis
`Alt+1…9` ouvrir un projet · `Alt+0` accueil · `Ctrl+K` changer de projet · `Ctrl+S` synchroniser

Code source et mode d'emploi complet : dépôt `BotTradingMeme`, dossier `taskboard/`.
