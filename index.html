⚙ Réglages & sauvegarde GitHub

Tes données sont toujours enregistrées dans ce navigateur. Relie un dépôt GitHub pour les retrouver sur tous tes appareils (PC, portable, téléphone) : chaque sauvegarde devient un commit d'un fichier JSON.

Comment créer le token ? (2 minutes)
  1. Crée un dépôt privé sur GitHub, par ex. mes-projets-data (coche « Add a README »).
  2. Va sur GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Repository access : Only select repositories → choisis ce dépôt.
  4. Permissions → Repository permissions → Contents : Read and write.
  5. Génère, copie le token (github_pat_…) et colle-le ici. Fais pareil sur chaque appareil (même dépôt, même fichier).
Le token reste uniquement dans ce navigateur (localStorage) : utilise-le sur tes appareils personnels.
